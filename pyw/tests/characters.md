# Convention

In this file, some characters are written as $q$-series starting with $1$. Some characters are written as $q$-series starting $q^{- \frac{c}{24}}$, where the central charge $c$ for a non-critical Kac-Moody algebra is given by the Sugawara formula:
$$
c = \frac{k\dim \mathfrak{g}}{k + h^\vee}
$$

The flavored character is defined as
$$
\operatorname{ch} = \operatorname{tr} q^{L_0 - \frac{c}{24}} \prod_i b[i]^{h^i}
$$
where $h^i$ 

## Notes on truncation accuracy (important)

For legacy/demo string-based character computation (e.g. `demos/Algebra.py::CharacterOfIntegrableModule`),
`order = N` should mean: **coefficients are correct through $q^N$**.

### What is a "prefix"?

- **$q$-series prefix**: the finite part
  $$
  a_0 + a_1 q + \cdots + a_N q^N.
  $$
- **string prefix** for one dominant maximal weight $\mu$: the finite list
  $$
  (m_\mu(0), m_\mu(1), \ldots, m_\mu(n_{\max})).
  $$

### Why can "prefix vs depth" be subtle in Sage?

`strings(depth=d)` is a computational cutoff, not a global character theorem.
In practice, you must verify that the string data needed by your final $q^N$ target is actually stable/complete.

A concrete pitfall is off-by-one usage: if code needs coefficient at index `n = d`, but calls `strings(depth=d)`,
that index may be missing. (So implementation should ensure the required range is present, e.g. ask at least `d+1` entries.)

### Recommended algorithm (exact-prefix assembly)

1. Choose target order $N$.
2. For each dominant maximal weight and each selected Weyl/translation representative,
   compute leading degree $d_0$.
3. Keep representative only if $d_0 \le N$.
4. Required string depth for that representative is
   $$
   n_{\max} = N - d_0.
   $$
5. Build only the required $q$-prefix
   $$
   a_0 + a_1 q + \cdots + a_N q^N.
   $$
6. Before final assembly, stabilize required string prefixes:
   increase `depth` until all required per-weight prefixes stop changing (or at least are complete to the required index range).

This method is faster than blind high-order recomputation and gives a correctness condition tied directly to the final target $q^N$.

### Why Weyl / translation are necessary in affine integrable characters

String functions are attached to **dominant maximal weights** only. They do not by themselves enumerate all weights in the module.
To reconstruct the full flavored character, one must generate the full set of contributing weights from these dominant data:

- **Weyl action** generates weights in the same Weyl orbit (different finite charges / monomials in $z_i$).
- **Translation action** (affine part) shifts along coroot directions and changes grade, which is exactly what controls the $q$-power.

So the assembly pattern is:

1. Start from dominant maximal weights and their strings.
2. Apply selected Weyl/translation representatives to obtain all needed orbit images.
3. Keep only representatives that can contribute to $q^0,\dots,q^N$ (using leading degree $d_0$).
4. Sum string depth only up to $n_{\max}=N-d_0$ for each representative.

Without Weyl/translation, the result is only a dominant-sector slice, not the full character.
